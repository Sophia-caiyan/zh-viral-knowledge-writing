# Output Recipes

Use this reference to decide what to produce for different user requests.

## Mode Selection

### Topic-To-Article

Use when the user gives a topic and asks for an article/post.

Output:

1. Reader diagnosis
2. Viral angle
3. Title set
4. Recommended title/subtitle
5. Opening
6. Body outline
7. Full draft if requested
8. Self-check

### Title Lab

Use when the user asks for titles only.

Output:

1. Reader pain in one sentence
2. 4 title strategies
3. 20 titles grouped by strategy
4. Top 3 recommendations with reasons
5. Risk notes for titles that may overpromise

### Draft Diagnosis

Use when the user provides a draft.

Score 1-5:

- Reader implication
- Title tension
- Opening scene
- Emotional truth
- Practical usefulness
- Evidence quality
- Shareability
- Ethical risk

Then provide:

- Biggest problem
- Fastest fix
- Revised title/subtitle
- Revised opening
- Structural rewrite plan

### Outline Builder

Use when the user wants structure before writing.

Output:

1. One-line thesis
2. Enemy or opposing force
3. Reader transformation
4. Section outline with purpose for each section
5. Examples/cases needed
6. Ending line

### Full Rewrite

Use when the user asks to rewrite content.

Output:

1. State assumptions.
2. Choose light edit or free rebuild.
3. Preserve factual claims unless the user asks to change them.
4. Rewrite with short paragraphs and scene-first opening.
5. Add a self-check explaining what changed.

### Free Rebuild

Use when the user provides a long draft but wants a stronger viral article, or when the original draft is too complete and may anchor the rewrite too much.

Output:

1. Extracted core thesis
2. New reader pain
3. New enemy/opposing force
4. 8-12 title candidates
5. Recommended title/subtitle
6. Rebuilt article that may change opening, sequence, examples, and ending
7. Self-check: what was preserved, what was discarded, what still needs evidence

## Default Format

Use concise Chinese headings:

- 读者诊断
- 角度
- 标题
- 推荐
- 开头
- 结构
- 结尾
- 风险

## Title Output Format

Group title candidates:

- 情绪代言型
- 反常识型
- 故事钩子型
- 实用干货型

For each recommended title, include:

- Why it works
- What the article must deliver
- Risk if any

## Article Outline Format

Use this structure:

1. 开头现场: concrete scene
2. 冲突升级: why this is not a small thing
3. 反常识观点: not X but Y
4. 机制解释: why it happens
5. 方法/框架: what to do
6. 例子迁移: how it applies to reader
7. 金句结尾: shareable final line

## Full Draft Rules

- Keep paragraphs short.
- Put examples before concepts.
- Avoid unsupported research claims.
- Use "比如", "我见过", or "一个典型场景是" for illustrative examples.
- Do not imply invented examples are real cases.
- For AI facts that may have changed, ask to verify or browse if the user requests current product details.
- When rewriting from a long source draft, avoid copying the user's section order unless the requested mode is light edit.
