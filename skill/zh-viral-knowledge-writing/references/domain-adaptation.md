# Domain Adaptation

Use this reference to convert domain knowledge into reader-facing long-form writing.

## AI Topics

Translate technical ideas into workflow consequences:

| Technical Topic | Reader-Facing Translation |
| --- | --- |
| Model capability | What becomes easier, harder, cheaper, or riskier in daily work. |
| Prompting | Whether the user has defined goal, context, constraints, and acceptance criteria. |
| Agents | Delegation, decomposition, supervision, and verification. |
| Automation | Trust, control, error cost, and recovery. |
| Tool choice | Habit, taste, workflow design, and decision quality. |
| Coding with AI | Specification, review, testing, and ownership. |

Strong AI article moves:

- Replace "AI will replace people" with a more precise cost or capability shift.
- Show two users using the same tool differently.
- Make judgment, decomposition, and verification the human value.
- Use simple work examples: writing email, reviewing code, preparing meeting notes, building a page, summarizing research.

Avoid:

- Current product facts unless verified.
- Empty trend language.
- Treating prompt formulas as magic.
- Claiming all jobs or all people will be affected in the same way.

## Psychology Topics

Translate concepts into lived moments:

| Concept | Reader-Facing Translation |
| --- | --- |
| Cognitive load | Too many decisions before the real work starts. |
| Boundary | Stopping the leak, not becoming cold. |
| Self-compassion | You cannot shame yourself into safety. |
| Attachment | A relationship pattern your body may read as danger. |
| Procrastination | A blocked start, not always laziness. |
| Rumination | Replaying a scene because no next action feels safe. |

Write with bounded language:

- Use "可能", "有时候", "常见的是", "可以试试".
- Separate everyday psychology from clinical diagnosis.
- If a topic touches disorder, trauma, medication, abuse, or self-harm, avoid advice beyond seeking qualified support.

Avoid:

- "你就是..."
- "只要...就一定..."
- Diagnosing the reader.
- Promising cure, healing, or permanent change.

## Coaching Topics

Make coaching visible through questions, choices, and contracts.

Translate coaching ideas:

| Coaching Idea | Reader-Facing Translation |
| --- | --- |
| Bad question | A loop that keeps the person proving the same story. |
| Better question | A door to a new choice. |
| Reflection | Seeing the repeated pattern, not reviewing every detail. |
| Accountability | Returning the decision to the person who will live with it. |
| Boundary | The contract of the conversation. |
| Action | The next observable behavior, not a mood. |

Useful article moves:

- Contrast advice-giving with helping someone see the real question.
- Show how a better question changes the direction of a conversation.
- Offer scripts: "你真正想避免的代价是什么？", "如果不证明自己是对的，你还会怎么选？"
- Keep the coach humble: the coach does not own the answer.

Avoid:

- Guru certainty.
- Presenting coaching as therapy.
- Turning composite scenes into real cases.
- Making ordinary friendship sound inferior.

## Workplace And Growth Topics

Translate ideals into cost, incentive, and behavior:

- "效率" becomes fewer bad decisions and less avoidable rework.
- "成长" becomes a new behavior under pressure.
- "复盘" becomes fact, choice, next step.
- "领导力" becomes the questions and systems that make better behavior easier.
- "职业安全感" becomes bargaining power, not comfort.

Strong moves:

- Start with a work scene where polite words hide real cost.
- Name the tradeoff.
- Give a rule the reader can use next week.
- End with an identity upgrade grounded in action.

Avoid:

- Corporate slogan language.
- Over-glorifying suffering.
- Pretending every workplace problem can be solved by mindset.
