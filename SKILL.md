# 中文爆款知识写作

Use this skill to turn any topic into a Chinese article or post with strong reader relevance, emotional tension, practical value, and shareable framing. Do not copy any creator's exact persona. Extract the transferable structure: concrete scene, reader pain, conflict, counterintuitive frame, useful method, and quotable ending.

## Load References

Read only the references needed for the request:

- For general use, always read `references/topic-adaptation.md`.
- For title, subtitle, opening, body, or style questions, read `references/mimeng-patterns.md`.
- For output formatting, mode selection, or deliverable shape, read `references/output-recipes.md`.

## Core Workflow

1. Diagnose the input topic.
   - Identify the target reader, platform, desired outcome, emotional pressure, reader misconception, available evidence, and risk level.
   - If the user gives little context, infer a practical default and state it briefly.
   - If the user provides a long draft, extract the core claim and usable facts first; do not preserve the draft's order unless the user explicitly asks for a light edit.

2. Choose the content engine.
   - Use emotional judgment when the topic contains injustice, shame, conflict, resentment, or a social norm.
   - Use story mystery when the topic has a surprising person, event, job, product, or transformation.
   - Use practical gain when the user needs saves, trust, learning, or conversion.
   - Use identity mirror when the topic separates beginners from experts or avoiders from actors.

3. Build the angle.
   - Convert abstract concepts into a reader-facing sentence: "This matters because you are losing/avoiding/misreading X."
   - Name the opposing force: a bad habit, false belief, social pressure, broken workflow, or hidden cost.
   - State a defensible reversal: "It is not X; it is Y."

4. Produce the requested artifact.
   - If the user asks for ideas: give angles and title sets.
   - If the user asks for structure: give title, subtitle, opening, section outline, and ending.
   - If the user asks for writing: draft in short paragraphs with scene-first opening and alternating emotion/usefulness.
   - If the user asks for complete rewriting: rebuild from the angle and reader pain, keeping only the original thesis/facts that should survive.
   - If the user asks for critique: score title, opening, body, evidence, shareability, and ethical risk.

5. Run the self-check.
   - Does the title make the reader feel implicated?
   - Does the first screen contain a concrete scene or conflict?
   - Is the central claim counterintuitive but supportable?
   - Does the piece offer useful method, not only emotional release?
   - Are claims bounded, especially for psychology, health, finance, law, or current AI product facts?

## Safety And Taste

- Be sharp, not cruel.
- Do not fabricate stories, data, research, user testimonials, or product claims.
- Avoid medical or psychological diagnosis unless the user provides qualified source material; use experiential language such as "可能", "常见", and "可以试试".
- Avoid humiliating vulnerable groups or turning stigma into a growth tactic.
- Use edgy phrasing only when the user's brand and platform support it.

## Default Response Contract

Unless the user requests a narrower output, provide:

1. Reader diagnosis
2. 3 angle options
3. 12 titles grouped by emotional, counterintuitive, and practical
4. Recommended title + subtitle
5. Opening draft
6. Article structure
7. Ending line
8. Self-check and risk notes
